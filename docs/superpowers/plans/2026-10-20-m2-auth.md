# Milestone 2 — Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Analysts and admins sign in at `https://ephoros.localhost/login`; Better Auth (Hono) issues
a 15-minute EdDSA JWT; FastAPI verifies it against Better Auth's JWKS and enforces roles; the
Angular app guards routes, refreshes the token silently and shows who is signed in.

**Architecture:** New Nx project `apps/auth` — Hono on Node 24 running TypeScript directly (type
stripping, no build), Better Auth with `jwt` + `admin` plugins, Drizzle on Postgres schema `auth`.
FastAPI is a resource server: `current_user` dependency (PyJWT + `PyJWKClient`) and
`require_role`. Angular gets `libs/web/core/auth` (Better Auth client, `AuthStore`, interceptor,
guards), `libs/web/feature-login` (Signal Forms), and Spartan helm components in `libs/web/ui`
with `hlm` backed by `cn`. Traefik routes `/api/auth/*` to `auth` with a rate limit.

**Tech Stack:** better-auth 1.7.12 · hono 4.13.13 · @hono/node-server 2.1.5 · drizzle-orm 0.45.4 ·
drizzle-kit 0.31.11 · pg 8.23.1 · PyJWT[crypto] 2.15.1 · @spartan-ng/cli + brain 1.8.0 ·
@angular/cdk 22.2.3 · cn 0.5.0 · class-variance-authority 0.7.1 · motion 14.4.0 · jose 6.2.13 (tests).

**Spec:** `docs/superpowers/specs/2026-10-10-ephoros-design.md` (§3.1, §4.2–4.4, §9.3, §10, §12, §12.1, §16, §17.2).

## Global Constraints

- Everything from the M1 plan's Global Constraints still holds (pins, just → Nx → uv/pnpm → mise,
  problem+json errors, `/api/v1` prefix, zoneless Angular, Nx tags). Run commands under `eval "$(mise env -s bash)"`.
- Versions above are exact pins (verified 2026-10-20). Better Auth's Drizzle adapter is imported from
  `better-auth/adapters/drizzle` (bundled — no extra package); the CLI is `pnpm dlx auth@1.7.12`.
- Roles are exactly `analyst` and `admin` (spec §9.3). Public sign-up is **disabled**; users are
  created server-side (seed script now, admin UI in M7).
- JWT: Better Auth default **EdDSA (Ed25519)**, `expirationTime: "15m"`, `issuer` = `BETTER_AUTH_URL`,
  `audience` = `"ephoros-api"`, payload `{ sub, email, name, role }` (via `definePayload`).
- FastAPI accepts only `algorithms=["EdDSA"]`, requires `exp`, `iat`, `sub`, checks `iss` and `aud`;
  JWKS via `PyJWKClient` (cached; unknown `kid` → one refetch, then 401). Missing/invalid token → 401
  problem+json with `WWW-Authenticate: Bearer`; wrong role → 403 (spec §9.3, §16).
- Auth service code is erasable-only TypeScript run by `node` directly: relative imports end in `.ts`;
  `tsconfig` has `allowImportingTsExtensions`, `erasableSyntaxOnly`, `noEmit`, `module: nodenext`.
- Env (add to `.env.example`, dev values point at `just dev`; Compose overrides for the TLS stack):
  `BETTER_AUTH_SECRET` (≥32 chars, dev-only value), `BETTER_AUTH_URL=http://localhost:4200`,
  `JWKS_URL=http://localhost:3000/api/auth/jwks`, `JWT_ISSUER=http://localhost:4200`,
  `JWT_AUDIENCE=ephoros-api`, `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `SEED_ANALYST_EMAIL`,
  `SEED_ANALYST_PASSWORD`.
- interior ports used here (spec §10 table): **Loading Button** and **Inline Validation** only, in
  `libs/web/ui/src/interactions/`, Motion `animate()`, honour `prefers-reduced-motion`, MIT header,
  listed in `THIRD_PARTY_NOTICES.md`. Floating Label / Password Strength are not needed (no sign-up).
- New Nx scope `scope:auth` for `apps/auth` (a TS service outside the web graph); it may depend only on
  `scope:auth` and `scope:shared`.
- Out of scope: user management UI and LLM settings (M7), SSE auth (M5), email verification, password
  reset, OAuth/SSO (spec §2.2).

### Per-task workflow (unchanged from M1)

TDD (failing test first) → ponytail smallest code → verification-before-completion → ponytail-review
on the task diff → fix → Conventional Commit. Milestone end: whole-branch review on a fresh reviewer →
ponytail-debt → finishing-a-development-branch.

## Review Focus

1. **Access token expires mid-session** — an API call after 15 min must refresh silently, never 401
   the user. Test in Task 6: `refreshes the token when it is about to expire`.
2. **Forged or mis-scoped JWTs** (HS256 signed with the public key, `alg: none`, wrong `aud`/`iss`,
   expired, other key) — always 401, never 500. Tests in Task 4.
3. **Auth service down while API is up** — cached JWKS keeps accepting valid tokens; an unknown `kid`
   with JWKS unreachable is 401, not 500. Test in Task 4: `test_jwks_unreachable_is_401`.
4. **Self-registration / role escalation** — `POST /api/auth/sign-up/email` must be rejected; a user
   cannot set their own role. Test in Task 1: `rejects public sign-up`.
5. **Open redirect through `returnUrl`** — only same-app paths (`/x`, never `//evil.com`,
   `https://…`) are followed after login. Test in Task 7: `ignores an external returnUrl`.
